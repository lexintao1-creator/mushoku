# 无职转生 · 归途之书

以六面世界为背景的 2D 同人网页 RPG 原型，包含中日文界面与死亡回归改编设定。当前发布为 2026-10-02 的第一批重制版本，并非完整大型游戏。

## 本地运行

在仓库根目录启动静态服务器后访问 `index.html`。不要依赖直接打开文件的方式，浏览器可能限制游戏素材加载。

## GitHub Pages

仓库根目录包含入口、脚本、样式及 `assets/`，保持现有 GitHub Pages 发布方式。

本次替换包含村落/森林地形与碰撞改进、水弹与石弹表现、独立角色施法和场景精灵、三态 HUD、触控及证据型救援后果。其余地区、火冰表现、室内场景和大型分支剧情仍在制作中。

测试截图、录像和内部参考资料不包含在本次发布中。原有旧素材暂保留，但新版入口不再引用旧地图和旧游戏脚本。
