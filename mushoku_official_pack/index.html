魔法体系

この作品の核は“魔法陣”です。属性、詠唱、術式、連鎖反応を UI で見せることで、画面自体が魔法演出になります。

聖光術式

回復・防護・浄化に特化。金色の魔法陣が広がり、前線の生存率を底上げする。

氷霧術式

制圧と遅延の術式。視界を奪い、敵の動線を止め、戦場を静かに支配する。

紅焔術式

高火力の属性反応。詠唱の終端で爆ぜる赤い輪が、画面ごと破壊の快感を演出する。

召喚紋式

結界・召喚・追撃を複合させる上位系。仲間の行動がそのまま陣形の拡張へ変わる。

キャラクター

立ち絵の魅力がそのまま世界観の説得力になるよう、四方向から役割が伝わる構成にしています。

MAGIC / SUPPORT

ルティナ

精密な詠唱を得意とする魔導士。戦況に応じて陣を切り替え、味方全体を支える。

SWORD / FRONTLINE

レオン

高速で間合いを詰める前衛剣士。魔法との連携で斬撃の軌跡自体が術式になる。

FLAME / CONTROLLER

ミリア

火焔を操る術者。広範囲を制圧し、敵の配置を壊すことで高難度戦の鍵を握る。

ICE / TACTIC

シグル

静かな導き手。氷の結界と支援魔法を駆使して、長期戦で真価を発揮する。

戦闘・育成

ただ殴るだけではない。属性反応、術式編成、仲間同士の連携、戦闘中のビルド変更が、RPGとしての深さを作る。

魔法陣がそのまま戦術になる。

陣の種類、展開速度、重ね掛けの順番、コンボの起点。UI を演出ではなく“戦術情報”として見せることで、操作体験とビジュアルの一体感を高めています。

✦

⟡

旅路育成
